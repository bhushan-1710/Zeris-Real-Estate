An ultra-premium, editorial-grade digital home for **Zeris Real Estate**, a boutique Mumbai & Lonavala real estate brokerage founded by **Sajid Zeri** and **Nausheen Zeri**.

---

## 🏛️ Concept: "Two Skylines"
Zeris Real Estate bridges two complementary property rhythms under one trusted relationship:
1. **Dense City High-Rises**: High-energy luxury apartments, sea-facing residences, and commercial assets across Mumbai's Western Suburbs (*Versova, Lokhandwala, Andheri West, Linking Road Bandra*).
2. **Slow Hillside Sanctuaries**: Standalone monsoon villas, mountain-view retreats, and clear-title weekend estates in the mist of *Lonavala Hills (Tungarli)*.

---

## ✨ Key Platform Features

- 🏛️ **Maharashtra Stamp Duty & Acquisition Cost Calculator**: Live computation of Maharashtra Stamp Duty (Male 6% / Female 5% / Joint 5.5%), Mumbai 1% Metro Cess, and the statutory ₹30,000 Government Registration fee cap.
- 📋 **Multi-Property Shortlist Tray**: Client-side property bookmarking saved via `localStorage` with one-click multi-property WhatsApp inquiry compilation.
- 🔗 **Deep-Linking & Share Dossier**: Direct property URLs (`listings.html?property=AZD-01`) that automatically load the full photo gallery and verified specification dossier.
- 📱 **Fluid Responsive Architecture**: 100% responsive across mobile, tablet, and desktop viewports with notch/home-bar safe area handling (`viewport-fit=cover`).
- ⚡ **Zero-Dependency Architecture**: Built with pure semantic HTML5, modern Vanilla CSS3 design system, and Vanilla JavaScript with instant load speeds.
- 💬 **Integrated Direct WhatsApp Touchpoints**: All consultation triggers and listing modals link directly to `+91 99208 97015`.

## 🚀 Running Locally

You can run this project locally with any static web server:

```bash
# Using Python 3
python -m http.server 3000

# Or using Node http-server
npx serve .
```

Then visit `http://localhost:3000` in your browser.
